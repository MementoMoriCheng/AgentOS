# 企业级 Java 设计文档（GNEX 架构参考）

> ⚠️ 本目录是**另一方向的探索性设计**，不是当前 AgentOS 的实现，也不是 V1（Go）的延续。
>
> 这些文档描述的是一个 **Java 企业级微服务架构（内部代号 GNEX）**：
> - Maven 多模块（`gnex-*-service`）
> - RocketMQ 消息总线、MyBatis-Plus
> - 独立的 Agent 核心 / 会话事件循环 / 编排 / 认证 / 运营 / 沙箱 / 数据层
>
> 原始来源 `GNexCore架构设计_2.1.html` 的源文件标注"已不在仓库"。

## 为什么保留

这些文档包含对未来**企业级部署**有参考价值的设计思路（如消息总线 Topic 规则、沙箱池管理、多租户认证、可观测性体系）。其中部分概念与 V2 架构（`docs/AgentOS架构设计重点关注V2.md`）的目标方向相通。

但它们**与当前 Python 控制面（`cp/`）的代码实现无直接对应关系**——当前没有 Java 代码、没有 Maven 工程结构。
