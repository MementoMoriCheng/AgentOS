# 模型适配设置页使用说明

## 入口

登录后打开：

```text
http://localhost:5173/settings
```

## 页面功能

### 系统自检

- **运行自检**：检查 LLM、MCP、Agent 和 Skill 的整体状态。
- **重连 MCP 后自检**：重连 MCP 后再执行系统检查。
- **模型连通性**：检查模型目录中各模型的厂商地址和开发/诊断环境 Key。

连通性状态包括：可用、未配置密钥、密钥无效、不可达。

### LLM 配置

配置平台级 API Key、Base URL 和默认模型。该区域主要用于本地开发与诊断，修改后点击页面底部的**保存**。

### 模型密钥（BYOK）

先选择 Provider，再配置对应密钥。

- **我的密钥**：当前用户专属，优先级最高。
- **租户兜底密钥**：仅管理员维护，在用户没有同 Provider 密钥时使用。
- 密钥使用 AES 加密保存，页面不会回显明文。
- BYOK 的保存和删除立即生效，不依赖页面底部的保存按钮。

运行时优先级：

```text
用户 BYOK > 租户 BYOK > 开发/诊断环境平台 Key
```

生产环境没有用户或租户 Key 时会直接报错，不回退平台 Key。

#### Base URL 高级设置

默认不需要填写，系统使用模型目录中的厂商地址。

以下场景可以展开**高级设置：Base URL**进行覆盖：

- Azure OpenAI
- 企业代理或模型网关
- 私有化部署模型
- OpenAI-compatible 自建服务

用户 Base URL 只影响当前用户；租户 Base URL 只作为该租户的兜底端点。清空后恢复模型目录默认地址。已有 Key 时可以只修改 Base URL，无需重新输入 Key。

### 模型注册表

查看或维护模型名称、上下文窗口和 Provider。该区域管理模型元数据，不保存模型密钥。

### 模型定价

配置每百万 Token 的估算价格，用于成本统计。修改后点击页面底部的**保存**。

### 智能体模型覆盖

为单个 Agent 指定模型。留空时使用全局默认模型，修改后点击页面底部的**保存**。

## 启动提示

- 前端使用 Vite 开发服务器时通常会自动热更新。
- 后端接口或 BYOK 存储逻辑发生变化后，需要重启后端进程。
